# Фоторедактор с ИИ

Фоторедактор, который работает в браузере. Обычные инструменты сочетаются в нём с функциями ИИ. Сборка не нужна: только HTML, CSS и JavaScript-модули.

## Возможности

**ИИ**
- **Авто-улучшение.** Редактор анализирует гистограмму и баланс белого и сам выставляет экспозицию, контраст, тени, света, температуру и сочность. Работает без сети, а подобранные значения можно поправить вручную.
- **Удаление фона.** Нейросеть [`@imgly/background-removal`](https://github.com/imgly/background-removal-js) работает прямо в браузере, фото никуда не отправляется. Новый фон можно сделать прозрачным, белым, любого цвета или размытым.
- **ИИ-ассистент (Claude).** Опишите результат словами, например «сделай как на закате» или «кинематографично». Claude посмотрит на фото и выставит ползунки, кратко объяснит изменения и предложит подпись для соцсетей.

**Редактирование**
- Свет: экспозиция, яркость, контраст, света и тени.
- Цвет: температура, оттенок, насыщенность и сочность.
- Эффекты: резкость, виньетка, зерно, выцветание, сепия, Ч/Б.
- 12 фильтров с превью на вашем фото.
- Обрезка в пропорциях 1:1, 4:3, 3:4, 16:9, 9:16 или свободная, поворот, отражение.
- Отмена и повтор (Ctrl+Z / Ctrl+Shift+Z), сравнение «До / После», сброс.
- Экспорт в полном разрешении в JPEG, PNG или WebP.
- Фото можно открыть кнопкой, перетащить в окно или вставить из буфера (Ctrl+V).

## Запуск

ES-модули не работают при открытии через `file://`, поэтому нужен любой статический сервер:

```bash
python3 -m http.server 8000
# откройте http://localhost:8000
```

## ИИ-ассистент

Для ассистента нужен API-ключ Anthropic. Введите его в блоке «API-ключ Anthropic» на вкладке «ИИ». Ключ хранится только в `localStorage` вашего браузера, запросы уходят напрямую в API Anthropic (модель `claude-opus-5-5`, структурированный JSON-ответ).

> ⚠️ Если ключ задаётся в браузере, его видно любому, у кого есть доступ к странице. Такой режим подходит для личного использования. Для публичного сайта запросы нужно проксировать через свой сервер.

## Структура

```
index.html          разметка интерфейса
css/styles.css      стили (тёмная тема, адаптивная вёрстка)
js/app.js           состояние, история, UI, обрезка, экспорт
js/processing.js    обработка пикселей, фильтры, авто-улучшение
js/ai.js            Claude API и удаление фона (грузится лениво)
```
