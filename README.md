# Фоторедактор с ИИ

Мобильный фоторедактор в браузере с нейросетями. Ставится на телефон как приложение (PWA) и работает без интернета.
Фото обрабатываются прямо на устройстве и никуда не загружаются.

**Стек:** React 19, TypeScript, Vite, Motion, Web Workers, Canvas API, vite-plugin-pwa (Workbox), Claude API,
@imgly/background-removal (ONNX в браузере), CSS Modules.

## Возможности

**ИИ**
- **Авто-улучшение:** анализ гистограммы и баланса белого подбирает экспозицию, контраст, тени, света и цвет. Работает без сети.
- **Удаление фона:** нейросеть работает на устройстве. Новый фон можно сделать прозрачным, белым, чёрным, своего цвета или размытым.
- **ИИ-ассистент (Claude):** опишите результат словами («кинематографично», «как на закате»), и Claude посмотрит
  на фото, выставит ползунки, кратко объяснит правки и предложит подпись для соцсетей.

**Редактирование**
- 15 настроек: свет, цвет, эффекты. Один крупный ползунок под палец, с «прилипанием» к нулю и сбросом по нажатию.
- 12 фильтров с превью на вашем фото и регулировкой силы.
- Обрезка пальцем в пропорциях 1:1, 4:5, 3:4, 4:3, 9:16, 16:9 или свободная, повороты, отражение.
- История правок: отмена и повтор, сброс к оригиналу.

**Жесты**
- Щипок двумя пальцами — масштаб, перетаскивание — сдвиг, двойной тап — увеличить или вернуть.
- Удержание пальца на фото — показать оригинал.
- На компьютере: колесо мыши, Ctrl+Z / Ctrl+Shift+Z, перетаскивание файла, вставка из буфера.

**Сохранение**
- JPEG, PNG или WebP в полном разрешении, с выбором качества.
- На телефоне кнопка «Поделиться» отправляет фото в «Фото», мессенджеры и так далее.

## Как устроено

- **Web Worker:** обработка пикселей идёт в отдельном потоке, поэтому интерфейс не подвисает. Предпросмотр рендерится по
  принципу «последний запрос побеждает»: пока воркер считает кадр, лишние запросы не копятся.
- **Предпросмотр и экспорт:** правки показываются на уменьшенной копии (1280 px на телефоне), а при сохранении
  применяются к фото в полном разрешении, тоже в воркере.
- **История:** холсты неизменяемы, каждое действие создаёт новый, поэтому отмена мгновенная.
- **Ленивая загрузка:** SDK Claude и библиотека удаления фона подгружаются только при первом использовании.
  Библиотека удаления фона берётся с CDN (версия зафиксирована), потому что модель (~40 МБ) она всё равно скачивает со своего сервера.

## Команды

```bash
npm install      # зависимости
npm run dev      # dev-сервер
npm run build    # проверка типов и сборка в dist/
npm run preview  # собранная версия с Service Worker
npm run lint     # линтер
npm test         # unit-тесты (Vitest)
npm run test:e2e # E2E-тесты в мобильном браузере (Playwright)
npm run icons    # пересобрать PNG-иконки из public/favicon.svg
```

## Тесты

- **Unit (Vitest):** обработка пикселей (без правок изображение не меняется, прозрачность сохраняется, значения в 0–255,
  виньетка, Ч/Б, температура), проверка диапазонов фильтров, авто-улучшение, история правок (черновик, отмена и повтор,
  отбрасывание «будущего», лимит 40 шагов, сброс), рамка обрезки для всех пропорций.
- **E2E (Playwright, экран iPhone 13):** авто-улучшение и отмена, ползунок и сравнение удержанием, двойной тап,
  фильтр, обрезка и поворот, ИИ-ассистент (ответ Claude подменяется), сохранение файла, работа без интернета.
- **CI:** `.github/workflows/ci.yml` на каждый пуш и PR запускает линтер, проверку типов, сборку и все тесты.

## ИИ-ассистент

Нужен API-ключ Anthropic: вкладка **ИИ → Добавить API-ключ**. Ключ хранится только на устройстве,
запросы идут из браузера напрямую в API (модель `claude-opus-5-5`, структурированный JSON-ответ).
Авто-улучшение и удаление фона работают без ключа.

> ⚠️ Ключ в браузере подходит для личного использования. Для публичного сервиса запросы нужно проксировать через свой сервер.

## Структура

```
src/
├── App.tsx                     сборка редактора: предпросмотр, загрузка, PWA, контекст
├── state/                      редьюсер с историей правок и контекст редактора
├── workers/render.worker.ts    обработка пикселей в отдельном потоке

├── lib/
│   ├── processing.ts           настройки, фильтры, авто-улучшение (чистые функции)
│   ├── image.ts                загрузка, повороты, обрезка, фон, экспорт, фото-пример
│   ├── renderFull.ts           полноразмерный рендер для сохранения
│   ├── ai.ts                   ИИ-ассистент на Claude
│   └── bgRemoval.ts            удаление фона
└── components/
    ├── layout/                 TopBar, ToolTabs, Welcome
    ├── stage/                  Stage (фото + жесты), CropOverlay
    ├── panels/                 AdjustPanel, FiltersPanel, CropPanel, AIPanel
    ├── export/                 ExportSheet, ApiKeySheet
    └── ui/                     Slider, Chip, Sheet, Toast, Icon
```

## Установка на Windows

Готовый установщик `.exe` лежит в **Releases** репозитория — релиз с тегом `ai-photo-editor-v…`.

1. Скачайте `ai-photo-editor-Setup-<версия>.exe` и запустите.
2. Если Windows покажет «Система Windows защитила ваш компьютер» — **Подробнее → Выполнить в любом случае**
   (установщик не подписан платным сертификатом, поэтому SmartScreen его не знает).
3. Выберите папку — ярлык «Фоторедактор с ИИ» появится на рабочем столе и в меню «Пуск».

Десктопная версия — это то же приложение в окне [Electron](https://www.electronjs.org/): `electron/main.cjs` открывает
собранный `dist` через свою схему `app://` (ведёт себя как https, поэтому работают модули, Web Workers и IndexedDB),
внешние ссылки уходят в браузер. Service Worker в этой сборке отключён (`DESKTOP=1`).

**Как выпустить новую версию:** поднимите `version` в `package.json` и запушьте в ветку —
`.github/workflows/release.yml` увидит, что релиза `ai-photo-editor-v<версия>` ещё нет, соберёт установщик на Windows и опубликует релиз. Собрать вручную на Windows:
`DESKTOP=1 npm run build && npm run dist:win` (результат — в `release/`).
